# CSS — Effects

---

## Hover

Pseudo-class — applies styles when mouse is over element.
```css
a:hover { color: yellow; }
button:hover { background-color: #333; }

/* hover on parent to affect child */
.nav li:hover > .dropdown { display: block; }
.card:hover .card-title { color: red; }
```

---

## Transitions

Smooths property changes instead of instant snap.
```css
a {
  color: black;
  transition: color 0.3s ease;   /* property duration timing-function */
}
a:hover { color: red; }          /* now fades instead of snapping */
```
```css
/* multiple properties */
button {
  transition: background-color 0.3s ease, transform 0.2s ease;
}
button:hover {
  background-color: #000;
  transform: scale(1.05);    /* slight grow on hover */
}
```

| Timing function | Does |
|---|---|
| `ease` | Slow start, fast middle, slow end (default) |
| `linear` | Constant speed |
| `ease-in` | Slow start |
| `ease-out` | Slow end |

## Animations

Two parts: define with `@keyframes`, apply with `animation` property.
```css
@keyframes slidein {
  from { transform: translateX(-100%); }
  to   { transform: translateX(0); }
}

.banner {
  animation: slidein 0.5s ease forwards;
}
```
```css
/* multiple steps */
@keyframes pulse {
  0%   { opacity: 1; }
  50%  { opacity: 0.4; }
  100% { opacity: 1; }
}

.alert { animation: pulse 1.5s infinite; }
```

**Animation properties:**

| Property | Does |
|---|---|
| `animation-name` | Name of `@keyframes` |
| `animation-duration` | How long one cycle takes |
| `animation-timing-function` | ease, linear etc |
| `animation-iteration-count` | Number of times or `infinite` |
| `animation-delay` | Wait before starting |
| `animation-fill-mode` | `forwards` = stay at end state after finishing |

Shorthand: `animation: name duration timing count delay fill-mode`

## Pseudo-elements

Target specific parts of an element — not in HTML, generated by CSS.
```css
p::first-line { font-weight: bold; }       /* first line of paragraph */
p::first-letter { font-size: 2em; }        /* drop cap effect */

.card::before {
  content: "★ ";     /* content is required — even if empty "" */
  color: gold;
}

.card::after {
  content: "";
  display: block;
  border-bottom: 1px solid #ccc;
}
```

> `::before` and `::after` are inline by default. Set `display: block` if you need width/height.

## Media Queries

Apply styles only at certain screen sizes — responsive design.
```css
/* applies only when screen is 768px or narrower */
@media (max-width: 768px) {
  .nav ul {
    flex-direction: column;   /* stack nav vertically on mobile */
  }
  .dropdown-menu {
    position: static;         /* flow in document instead of floating */
  }
}
```

| Breakpoint | Device |
|---|---|
| `max-width: 480px` | Mobile |
| `max-width: 768px` | Tablet |
| `min-width: 1024px` | Desktop |

## Common Mistakes

- `transition` on hover rule instead of base rule — transition won't apply on mouse-out.
- `@keyframes` name mismatch with `animation-name` — nothing plays, no error shown.
- `::before` / `::after` not showing — missing `content: ""` property, it's mandatory.
- Media queries order matters — put mobile styles after desktop or use `min-width` vs `max-width` consistently, don't mix randomly.
